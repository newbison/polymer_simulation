File Structure & Development Approach

Minimal, flat structure — no build tools, no frameworks

Project Tree

polymer_simulation/
├── index.html          ← entry point
├── css/
│   └── style.css       ← all styles
├── js/
│   ├── main.js         ← loop + wiring
│   ├── simulation.js   ← particle system + kinetics
│   ├── renderer.js     ← Canvas drawing
│   └── ui.js           ← control panel + events
└── README.md           ← how to run & use

Key Details

DependenciesZero — vanilla JS, ES modules
Canvas API2D context, no WebGL needed
Run locallyOpen index.html in browser
ShareHost on any static server (GitHub Pages, Netlify)
Target perfSmooth at 200+ particles on any device

Development Order

  1. Scaffold — HTML structure, CSS layout, dark theme
  2. Renderer first — get particles drawing on Canvas with Brownian motion (no reactions yet)
  3. Simulation core — initiator decomposition, propagation, termination with proximity rules
  4. UI wiring — sliders → params, play/pause/reset, live readouts
  5. Callout overlay — ball-and-stick inset for key reaction events
  6. Polish — colors, glow effects, chain visualization, transitions

Design Summary

AudienceStudents — educational
VisualizationHybrid — schematic canvas + ball-and-stick callouts
InteractivityFull simulation — adjustable params, play/pause/scrub
PlatformWeb — vanilla JS, Canvas 2D, no dependencies
ChemistryInitiation + propagation + termination (combination & disproportionation)
Architecture4 modules — main, simulation, renderer, ui
