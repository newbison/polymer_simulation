Module Responsibilities

Module Owns Exposes
simulation.js Particle positions & velocities
State machine: initiation → prop. → termination
Kinetic rates (kd, kp, kt)
Chain tracking & conversion stats 		tick(dt) — advance one frame
getState() — all particle data
getStats() — conversion, Mn, PDI
setParams(p) — update kinetics
reset()
renderer.js Canvas context & drawing logic
Schematic circle/line rendering
Ball-and-stick callout overlay
Color palette & visual states 		draw(state, stats) — render frame
resize(w, h) — handle resize
ui.js DOM for control panel
Sliders, buttons, readouts
Event listeners → callbacks 		onPlay(fn)
onReset(fn)
onParamChange(fn)
updateReadouts(stats)
main.js requestAnimationFrame loop
Wiring modules together
Pause/play state 		start() — entry point

Data Flow

Each frame: main.js calls sim.tick(dt) → gets state → passes to renderer.draw(state). UI events flow the other way: slider change → callback → sim.setParams().
